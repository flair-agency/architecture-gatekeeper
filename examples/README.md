# Consumer examples

Start with [consumer-v4](consumer-v4/README.md) for a complete input tree with
local configuration v2, enforced CI policy v4, caller wiring, and the separate
optional G0 selection. [`config.json`](config.json) is its local v2 config
companion.

[`legacy-v1/config.json`](legacy-v1/config.json) preserves the former v1
configuration example byte-for-byte for existing integrations. It is
deprecated for new setups; see the [migration note](../docs/integration-reference.md#deprecated-legacy-local-configuration-v1-and-ci-policy-v1).
