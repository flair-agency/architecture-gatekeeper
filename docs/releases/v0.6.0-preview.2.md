# v0.6.0-preview.2

This corrected preview includes the consumer workflow and finalizer fixes from
PR #275. The existing v0.6.0-preview.1 release remains immutable.

## Consumer upgrade

- Install exactly `@flair-agency/architecture-gatekeeper@0.6.0-preview.2`.
- Pin ordinary consumer callers to
  `flair-agency/architecture-gatekeeper/.github/workflows/architecture-gate-consumer.yml`
  at this release tag's exact peeled source commit. Align runtime, lockfile and
  Skill revision with that source.
- Ordinary callers require `contents: read` and `pull-requests: write`, without
  self-only OIDC or attestation grants. Existing self producers keep their
  original workflow and signer identity.
- OWNER_ADDITION finalization recognizes both supported workflow entrypoints
  and obtains defaults from the exact recorded-base caller selection.
- Legacy v1 consumers must follow the protected selection/adoption procedure
  in `docs/integration-reference.md`. Package installation does not adopt
  protected policy. There is no automatic compatibility fallback or newly
  authorized administrative bypass.

## Limits

This release does not activate OWNER_AMENDMENT, complete formal v0.6.0 E2E
requirements, or prove a real consumer's protected adoption. Failed or
incomplete reviews remain unsuccessful. Provider contract documentation on the
source branch does not activate Gemini execution or any fallback.

The preview registry channel advances to this version; stable `latest` remains
0.5.1. Use exact version and source pins when reporting regressions.
