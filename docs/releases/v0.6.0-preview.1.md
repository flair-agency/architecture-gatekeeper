# v0.6.0-preview.1

This preview is for feedback on Architecture Gatekeeper's existing review
paths. Install this exact version when evaluating it; do not use a floating
version selector.

## Included feedback areas

- Ordinary `PASS` decisions follow the configured success path.
- When a consumer schema selects validated `findings` and GitHub permissions
  allow review comments, CI can report bounded inline PR feedback. The feature
  is optional and does not change the acceptance decision.
- Reports present the decision and available usage/tool counts more clearly.
  Numeric telemetry is bounded and may be unavailable; it is not cost
  attribution or proof of the provider's effective service tier.
- Existing local, manual, native Skill, CI and `OWNER_ADDITION` paths remain
  available under their existing configuration and assurance limits. Reporting
  details vary by path.

## Try it

Install `@flair-agency/architecture-gatekeeper@0.6.0-preview.1` from GitHub
Packages with the consumer repository's existing exact-version installation
procedure. Keep the Skill revision and reusable workflow commit aligned with
the same release source where those integrations are used.

Please report setup failures, unexpected decision routing, findings/report
usability, and compatibility regressions. Include the review path, package
version, and a minimal reproduction; omit secrets and private authority text.

This preview does not complete the v0.6.0 self-reference or amendment lifecycle
requirements and does not enable the protected `OWNER_AMENDMENT` route.
