# Issue #83 real-PR BLOCK probe implementation

Status: test-only implementation awaiting protected-main execution. This is not a production ReviewRecord, an accepted evidence route, or a G0 policy change. The workflow is inactive unless the repository owner sets the protected Actions variable `ISSUE83_FIXTURE_PR` to the decimal number of one ready-for-review fixture PR. It can run only after the workflow and producer script are merged into protected `main`; a PR containing the workflow cannot execute its own candidate version through `pull_request_target`.

The fixture should make one clear proposal to accept an incomplete architecture review, with no executable code, and remain unmerged. The existing self gate should report `BLOCK` for that head. The dedicated workflow checks the reviewed merge commit's parents against the event's base and head, requires its workflow revision to equal the protected base, and fails if the merge ref changes during execution. It uses the protected-base policy, prompt, schema, validation rules and complete Authority Set. The review job has the model credential and read-only repository permission, while the producer job alone has OIDC and attestation permission. The producer independently materializes the Authority Set, validates the exact decision and its reported IDs, and emits a record only for a completed top-level `BLOCK`.

After the run, fetch `issue83-real-pr-block-<run-id>-<attempt>` and retain its exact JSON bytes. From a separate read-only environment, run `gh attestation verify <record-path> --repo flair-agency/architecture-gatekeeper --signer-workflow .github/workflows/issue83-real-pr-block-probe.yml --format json`. Inspect the verified certificate and statement for the expected protected source commit and run attempt, and compare its subject digest with the bytes. Independently fetch the referenced PR, base, head and merge Git objects and the protected inputs to check the record's identities and digests. The certificate does not contain a job ID; the reviewed workflow's protected job sequence supplies that producer guarantee. The record and artifact name alone supply no authenticated identity.

Exercise a full rerun and a producer-only rerun. The latter must fail because it cannot download a decision from its own attempt. Test changed head/base, edited or substituted record, wrong signer or attempt, incomplete review and deleted or expired bytes. Record which failures were observed on GitHub and which used local fixtures. Close the fixture PR without merge and unset `ISSUE83_FIXTURE_PR` after the experiment. A missing claim or unavailable exact bytes is `INCOMPLETE`, not an acceptable historical `BLOCK`. Long-term byte retention and private/internal repository availability remain open before #78 can use this route.
