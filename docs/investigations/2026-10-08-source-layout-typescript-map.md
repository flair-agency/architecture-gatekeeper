# Production source and staged TypeScript migration map (#417 / #419)

> Non-normative planning inventory for the shared package. It records the baseline implementation paths and a current authoring/build map; it does not change consumer architecture, assurance, acceptance, route selection, or the selected Authority Set. This is partial planning work and does not close #417 or #419.

## Baseline and scope

The initial map at `44b311d` records **96** production `src/**/*.mjs` modules, measured by `rg --files src -g '*.mjs'`; #417’s issue text describes an earlier 92-module baseline. The package is ESM, requires Node `>=22`, pins Acorn `8.19.0` for development, and had no TypeScript compiler, build, or type-check command at that map revision. At that revision `package.json#files` distributed `src/` but no TS authoring tree. Existing tests, scripts, and workflows referred directly to flat `src/*.mjs` paths.

Grouping is a source-navigation proposal around existing responsibility areas, not a new API layer, host abstraction, or runtime responsibility. All six selected normative members remain controlling. Static types do not validate external bytes, establish authenticity/provenance, replace runtime validators, or make a semantic result acceptable.

## Compatibility and caller inventory

Keep `.mts` as the authoring extension: TypeScript NodeNext emits `.mjs`, matching the ESM runtime identity. Place editable compatibility facades in `src/` and emitted runtime files in ignored `dist/`. Emit implementation modules in responsibility folders where they can move; keep preview lifecycle source and runtime paths flat because its source-relative runtime identity depends on that location. This keeps current source facades available while tests, scripts, workflows, and integrations migrate independently. A facade may forward CLI dispatch only after a named runner and direct-execution boundary are established; a plain re-export does not preserve a private `main` or an unguarded module body. Add direct-run and inert-import checks before converting each executable path. Public consumers continue to execute JavaScript and install no compiler.
