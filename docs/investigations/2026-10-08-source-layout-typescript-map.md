## Baseline and scope

Clean main has **96** production `src/**/*.mjs` modules, measured by `rg --files src -g '*.mjs'`; #417’s issue text describes an earlier 92-module baseline. The package is ESM, requires Node `>=22`, pins Acorn `8.19.0` for development, and this baseline has no TypeScript compiler, build, or type-check command. `package.json#files` currently distributes `src/`; tests, scripts, and workflows refer directly to flat `src/*.mjs` paths. The proposed migration retains `src/` as the single editable source root for JavaScript and TypeScript and emits generated JavaScript into Git-ignored `dist/` with standard NodeNext `tsc`; those changes belong to #431 and are not present on this planning branch.

Grouping is a source-navigation proposal around existing responsibility areas, not a new API layer, host abstraction, or runtime responsibility. All six selected normative members remain controlling. Static types do not validate external bytes, establish authenticity/provenance, replace runtime validators, or make a semantic result acceptable.
